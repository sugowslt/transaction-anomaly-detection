# 이체 판별 입력 계약

저장형 이체 판별 API(`POST /api/bank/events`)는 거래금액, 거래시간대, 자금구분, 매체구분만 받습니다. 계좌와 금융회사 식별자는 모델 입력과 저장 대상에서 제외합니다.

## 확인 근거

2026년 9월 23일 AI Hub [「이상 판별을 위한 금융거래 정보 및 사용자 패턴 합성데이터」](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=71925) 페이지와 해당 페이지에서 제공하는 구축활용가이드 v1.4를 확인했습니다. 공식 자료는 전자금융공동망의 네 입력 열을 필수값으로 표시하고, 시간대·자금·매체 코드의 범위와 의미를 정의합니다.

| 필드 | 공식 자료 정의 | 이 프로젝트의 입력 |
| --- | --- | --- |
| `거래금액` | 필수, Number | 0 이상 100,000,000,000,000,000 미만, 소수 둘째 자리까지의 JSON 숫자 |
| `거래시간대` | 필수, String | `0`, `3`, `6`, `9`, `12`, `15`, `18`, `21` 중 하나인 JSON 숫자 |
| `자금구분` | 필수, String | 학습 파일에서 확인된 `0`, `1`, `3`, `4` 중 하나인 문자열 |
| `매체구분` | 필수, String | `1`부터 `7`까지 중 하나인 문자열 |

거래시간대 코드는 시작 시각을 뜻합니다. `0`은 00~02시, `3`은 03~05시이며 같은 방식으로 `21`은 21~23시를 나타냅니다.

| 매체구분 | 의미 | 자금구분 | 의미 |
| --- | --- | --- | --- |
| `1` | PC 뱅킹 | `0` | 일반 |
| `2` | 인터넷 뱅킹 | `1` | 급여 |
| `3` | 전화 | `3` | 기타 |
| `4` | 휴대전화 | `4` | 타행 자동이체 |
| `5` | 건별이체 | `11` | 기초생활보장급여(압류금지) |
| `6` | 기타 |  |  |
| `7` | 대량이체 |  |  |

공식 코드표에는 자금구분 `11`이 있지만, 현재 학습 파일과 모델 매핑에서는 확인되지 않았습니다. 학습하지 않은 범주를 임의로 다른 값으로 치환하지 않기 위해 API는 `11`을 HTTP 400으로 거부합니다.

## 요청 예시

```json
{"거래금액":5000000,"거래시간대":9,"자금구분":"0","매체구분":"2"}
```

필드가 빠졌거나 추가 필드가 있거나 자료형과 코드 범위가 다르면 HTTP 400을 반환합니다. 이 계약은 현재 학습 모델이 처리할 수 있는 범위를 나타내며, 공식 코드 전체를 지원한다는 뜻은 아닙니다.

금액은 H2의 `DECIMAL(19,2)` 저장 형식에 맞춰 검사합니다. 소수 셋째 자리 이하에 유효한 값이 있으면 저장 시 반올림될 수 있어, 모델에 전달하기 전에 HTTP 400으로 거부합니다.
상한값에 매우 가까운 금액도 모델의 실수 변환 과정에서 상한값으로 반올림되면 거부합니다.

모델 서비스가 유효한 요청을 거부하거나 경보 여부가 점수와 기준값에 맞지 않으면 HTTP 502를 반환하고 판별 결과를 저장하지 않습니다. 모델 서비스의 오류 본문은 클라이언트에 전달하지 않습니다.

## 운영 연동 전에 확인할 사항

공식 자료는 합성 데이터의 열과 코드 정의를 설명하지만, 실제 금융 시스템이 판별 시점에 네 값을 모두 제공한다는 내용은 확인되지 않았습니다. 운영 연동 전에는 거래 승인 흐름의 실제 요청 스키마, 코드 버전, 누락 가능성, 응답 제한 시간을 별도로 확인해야 합니다.
